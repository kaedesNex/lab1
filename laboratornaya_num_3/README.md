# Лабораторна робота №3. Колекції, рядки, пошук і сортування
- Варіант №18 "Каталог фільмів"
- Мова/стандарт: C++20

## Призначення
Програма дозволяє вводити невеликий каталог фільмів.
Дозволяє знаходити кіноматеріали по:
- Назві;
- Фільтрації фільмів тривалістю менше за 12 хвилин;
- Статистиці й сортуванню по спаданню тривалості.

## Опис
Користувач вводить кількість кінолент N, а потім для кожного фільму: назву, тривалість у хвилинах.
Після введення N корректних записів програма послідовно виводить:
- Каталог у порядку введення;
- Результати пошуку за введеним запитом;
- Фільми, коротші за 12 хвилин, або ж повідомлення про їх відсутність;
- Статистику: кількість, сума, середнє, мінімум і максимум тривалості;
- Каталог, відсортований по тривалості за спаданням.

## Вхідні дані та правила
- Кількість фільмів|0-20|
- name(назва кіноленти)|не порожня після зрізання пробілів та не більша за 60 байт|
- duration(тривалість у хвилинах)|1-25|
- Пошуковий запит|знову ж, не порожній після обрізання пробілів|
Додаткові правила:
- При введенні кириличного алфавіту можна ввести лиш, приблизно, 30 букв, через те що у UTF-8 одна кирилична літера = 2 байтам;
- `readMovie` має обмеження у 30 кіно-відеоматеріалів. Тож через ліміт у N =< 20 воно не спрацьовує, це просто додаткова міра безпеки;
- Сортується йде по тривалості за спаданням. Порядок фільмів з однаковою тривалістю, нажаль, не гарантується.

Порядок введення:
N -> (name -> duration) × N -> пошуковий запит.

Назву вводиться рядком, кожне ж значення - з нового рядка. Якщо після чисел N або тривалості є ще якісь символи, вони ігноруються.

Також середнє значення виводиться по ось такій формулі:
`average = static_cast<double>(sum) / durations.size()`;
Та виводиться з двома знаками після коми.

## Помилки введення
- Якщо N виходить за межі 0-20, програма повторно запитає N.
- Якщо N не є числом, або введення завершилось, програма виведе повідомлення про помилку і завершиться.
- Якщо назва порожня або ж довша за 60 байт, повторно запитується лиш назва.
- Якщо тривалість виходить за межі 1-25, повторно запитується тільки тривалість. Вже введена назва зберігається.
- Якщо тривалість не є числом, чи введення завершилось під час введення фільму, програма виведе повідомлення про помилку та завершиться.
- Якщо запит для пошуку порожній, програма повторно його запитує. Якщо ж введення завершилось - програма завершиться.

Особливі випадки:
- Якщо N = 0, програма видасть "Catalog is empty.", результат пошуку "Theres no matches", повідомлення про відсутність коротких фільмів, в статистиці буде — `Count: 0`, `Sum: 0 min` та `Average: catalog is empty` (мінімум і максимум виводитись не будуть).

## Збірка та запуск
1. Visual Studio: створити консольний проект C++, додати "lab3.cpp", вибрати C++17 або новіший стандарт, зібрати і запустити, натиснувши Ctrl + F5. Програма відкриється у терміналі, та буде очікувати вводу даних.
2. g++(Потрібна наявність компілятора g++ з підтримкою C++17): "g++ -std=c++17 -Wextra -pedantic lab3.cpp -o lab3.exe".

## Перевірки
У коді є `assert` для функції `trim`: перевіряється обрізання пробілів (`" short Comedy "` -> `"short Comedy"`) та обробка рядка з самих пробілів (результат порожній). Також у функціях роботи з каталогом `assert` перевіряє, що вектори `names` і `durations` мають однакову довжину.
`assert` також не заміняє перевірку введення. Якщо ж NDEBUG визначено, ці перевірки вимикаються.
