# ЛБ1 — Лінійні та розгалужені алгоритми
- Дисципліна: Основи програмування
- Група: ІІТ-26-1
- Варіант: №18 "Статус проходження за відвідуванням і результатом"
- Мова/стандарт: C++

## Призначення
Програма виконує сценарій для перевірки допуску студента до заліку на основі трьох вхідних даних:
1.Загальна кількість занять
2.Загальна кількість відвіданих занять
3.Отриманий балл
Програма вираховує спочатку неокруглений відсоток відвідуваності та визначає один із трьох взаємовиключаючих статусів успішності з урахуванням пріорітету умов.

## Вхідні дані та правила
Вхідні значення з типами:
1.totalClasses(int) - загальна кількість занять, межі від 1 до 100
2.attendedClasses(int) - відвідані заняття, межі є загальною кількістю занять (від 0)
3.score(int) - балл, межі від 0 до 100

Формула:
attendancePercent = 100.0 * attendedClasses / totalClasses

Приорітет умов:
1.Якщо attendancePercent < 60 тоді "Not allowed"
2.Інакше, якщо score < 50 тоді "Accepted, but the result threshold is not reached"
3.Інакше "Conditional pass"

## Збірка та запуск
Для роботи у Visual Studio:
1.Запустіть Visual Studio, оберіть "Create a new project" потім "C++ Console App". Назвіть якось проект та вкажіть шлях до робочої папки.
2.Скопіюйте вміст файлу "var18.cpp" у створений за замовчуванням файл "Source.cpp".
3.Натисніть у верхньому меню "Build" потім "Build Solution". Також переконайтесь в Output що збірка пройшла без помилок.
4.Натисніть F
