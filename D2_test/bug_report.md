## Bug report: втрата дробової частини середнього

## Контракт
Для 0 ≤ sum ≤ 3000, 1 ≤ count ≤ 30; average повинна повертати дробову частину sum / count.

## Відтворення
Початковий вираз: static_cast<'double'>(sum / count)

1. Викликати average з аргументами 5 і 2;
2. Вивести отримане значення

Очікуваний результат - 2.5;
Фактичний до виправлення - 2.

## Причина помилки
Обидва елементи мають тип 'int'. Тому спочатку виконується цілочисельне ділення, яке відкидає дробову частину. А подальше перетворення у 'double' не відновлює її.

Тому функція повертає неправильне середнє для випадків, коли sum не ділиться на count націло.

## Спостереження у налагоджувачі

Було виконано на breakpoint перед return для sum = 5 і count = 2
У watch спостерігалося:
- sum = 5
- count = 2
- sum / count = 2
- static_cast<'double'>(sum / count) = 2
- static_cast<'int'>(sum / count) = 2
- static_cast<'double'>(sum) / count = 2
- static_cast<'int'>(sum) / count = 2.5
