# Лабораторна робота №2. Потокова обробка даних
- Варіант №18 "Відвідування й результат"
- Мова/стандарт: C++20

## Призначення
Програма призначена для аналізу відвідуваності та результатів студентів. Для кожного студента вона обчислює:
- Відсоток відвідування;
- Визначає статус за умовами варіанта;
- Формує на основі цих даних загальну статистику.

## Опис
Користувач вводить кількість студентів N, а потім для кожного студента: загальну кількість занять, кількість відвіданих, бал.

Потім програма послідовно оброблює отримані записи, зберігаючи лише дані поточного студента та накопичену статистику.

Після обробки N коректних записів виводиться:
- сума та середнє значення відсотків відвідування;
- мінімальна й максимальна відвідуваність із номерами перших введень;
- кількість студентів, які відповідають умові пошуку;
- номер першого такого студента, або повідомлення про відсутність збігань;

## Вхідні дані та правила
- totalClasses(загальна кількість занять)|1-30|
- attendedClasses(кількість відвіданих занять)|0-totalClasses|
- score(бал)|0-100|

Порядок введення:
totalClasses -> attendedClasses -> score.

Вводити дані можна як послідовно, кожні з нового рядка, так і через пробіли в один.

- Формула:
m = 100.0 * attendedClasses / totalClasses

## Помилки введення
- Якщо N виходить за меді 1-30, програма повторно запитає N.
- Якщо введення завершується, або неможливо прочитати очікувані числа до отримання всіх даних, то програма завершиться без підсумкової статистики.
- Якщо поля студента порушують допустимі межі або залежності, повторно вводяться всі три поля цього студента. Статистика й кількість прийнятих записів не зміниться.

## Збірка та запуск
1. Visual Studio: створити консольний проект C++, додати "lab2.cpp", вибрати C++17 або новіший стандарт, зібрати і запустити, натиснувши Ctrl + F5. Програма відкриється у терміналі, та буде очікувати вводу даних.
2. g++(Потрібна наявність компілятора g++ з підтримкою C++17): "g++ -std=c++17 -Wextra -pedantic lab2.cpp -o lab2.exe".

## Перевірки

Assert також не заміняє перевірку введення. Якщо ж NDebug визначено, ці перевірки вимикаються.
